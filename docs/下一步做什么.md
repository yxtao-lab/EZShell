## 一句话结论

**P2 已合入桌面端**：SFTP、命令片段、端口转发、EZShell 备份（明文/加密）、OpenSSH / MobaXterm 导入、设置页入口。  
下一步优先：**用真实 SSH 主机与真实 Moba 导出文件验收**，通过后进入 **P3**（会员权益与云同步）。

---

## 立刻怎么跑桌面端

```bash
pnpm build:packages
pnpm --filter @ezshell/core test
pnpm dev:desktop
```

### P2 自测清单

1. 连接主机后切换「SFTP」：浏览 / 上级 / 刷新 / 上传 / 下载 / 重命名 / 删除  
2. 「片段」新建含 `{user}@{host}` 的命令 → 有活动会话时发送；无会话时应提示「当前没有活动终端会话」  
3. 「端口转发」新建 Local 规则并启动 → 本机访问绑定端口可达远端目标；停止后释放  
4. 「设置」导出明文 JSON 与加密 `.ezb` → 换口令失败有提示 → 合并导入成功  
5. 导入 `docs/fixtures/openssh/sample_config` 与 `docs/fixtures/moba/sample.mxtsessions`  
6. 用真实 `.mxtsessions` 再验一次（仅 `#109#`、分组、去重、密码不可还原备注）

## 验收通过后：P3 做什么

会员权益、设备会话、手动开通订单、端到端加密云同步（主机元数据 / 分组 / 片段 / 转发；密钥密码默认不上云）。

---

## 已知说明

- 本地 API 仍默认 **SQLite**  
- `ssh2` 原生加速未编译时可回退 JS  
- 备份加解密仅主进程使用（`@ezshell/core/backup-crypto`），避免渲染进程打入 Node crypto  
- 样例文件见 `docs/fixtures/`
